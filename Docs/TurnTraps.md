# กับดักตามเทิร์น — TESTMAP1Version2

เปิด `Assets/Scenes/Mon/TESTMAP1Version2.unity` และดูกลุ่ม `Turn Trap Examples` ใน Hierarchy

- `Spike Trap - Every 2 Turns`: แผ่นหนามบนช่อง Grid (1, 1) ใกล้จุดเริ่มต้น
- `Arrow Trap - Every 3 Turns`: แท่นยิงทางขอบซ้าย ยิงไปทาง +X ตามแถว Grid Z = 1

ลำดับของหนึ่งเทิร์นคือ Player → Enemy → Traps → เพิ่มเลขเทิร์น
การกด Skip ของตัวละครแต่ละตัวไม่ทำให้กับดักนับเพิ่ม; ต้องจบคิวผู้เล่นทั้งหมด
หรือกด End Turn จึงเข้าสู่ช่วงท้ายเทิร์นหนึ่งครั้ง

## รอบการทำงาน

| ตอนจบเทิร์น | หนาม | ธนู |
|---|---|---|
| 1 | ไม่ทำงาน | ไม่ยิง |
| 2 | พุ่งขึ้นและค้างไว้ | ไม่ยิง |
| 3 | ยังขึ้นค้าง | ยิงหนึ่งลูก |
| 4 | ยังขึ้นค้าง (ถ้าเคยถูกสั่งลง จะขึ้นอีกครั้ง) | ไม่ยิง |
| 5 | ยังขึ้นค้าง | ไม่ยิง |
| 6 | ยังขึ้นค้าง (ถ้าเคยถูกสั่งลง จะขึ้นอีกครั้ง) | ยิงหนึ่งลูก |

ฉากตั้งขีดจำกัดไว้ 5 เทิร์น หนามขึ้นตั้งแต่ท้ายเทิร์น 2 และค้างจนมี Event สั่งลง ส่วนธนูยิงเทิร์น 3
หากต้องการลองรอบ 6 ขึ้นไป ให้เพิ่ม Maximum Turns ที่ TurnGameManager

หนามทำร้าย Character ที่ยืนบนช่องเป้าหมายตอนพุ่งขึ้น และตัวที่เดินเข้ามาขณะหนามยังขึ้นอยู่
ตรวจจาก Event OccupantChanged ของ Tile ทันทีที่เดินมาถึง จึงไม่เดินผ่านหนามไปเปิดประตู/ชนะเกมหลังตาย
ธนูหยุดเมื่อชนกำแพง/ประตูปิด หรือโดน Player คนแรกตามแนวยิง
รองรับ Collider แบบ Trigger และ Collider บนวัตถุลูกของ Player
ความเสียหายใช้ ReceiveHit ของ Character ตามระบบเดิม; Player ในฉากตั้ง CanKill เป็น true จึงตายเมื่อโดน
เมื่อ Player ตายหมดจะแสดง Game Over แม้ไม่มีตัวละครที่ถูกเลือกอยู่
หนามขึ้นแล้วเกมเดินเทิร์นต่อได้เลย ส่วนธนูต้องจบการเดินทางก่อนเริ่มคิวใหม่

## Event สั่งหนามลง (เตรียมไว้ ยังไม่มีตัวเรียกในเกม)

`SpikeTrapEvents` ประกาศ C# event `LowerRequested` และ `TurnSpikeTrap` สมัครรับใน OnEnable
พร้อมยกเลิกการรับใน OnDisable เพื่อไม่ให้มีตัวรับค้างเมื่อปิดวัตถุหรือเปลี่ยนฉาก
ในอนาคต เมื่อกำหนดเงื่อนไขแล้ว สคริปต์นั้นสามารถส่งคำสั่งไปยังกับดักที่ต้องการได้:

```csharp
SpikeTrapEvents.RequestLower(targetSpikeTrap);
```

คำสั่งนี้ลดเฉพาะ `targetSpikeTrap`; กับดักอื่นยังคงสถานะเดิม
ปัจจุบันไม่มีสวิตช์ ปุ่ม หรือเงื่อนไขใดเรียกคำสั่งนี้ หนามจึงไม่ลงเองตามเวลา
ดูสถานะผ่าน `TurnSpikeTrap.IsRaised` ได้ และหากถูกสั่งลง หนามจะขึ้นอีกเมื่อถึงเทิร์นที่หาร Interval Turns ลงตัว
การปิด/เปิดวัตถุชั่วคราวคงสถานะหนามเดิม; Restart สร้างฉากใหม่และเริ่มด้วยหนามลง

## นำไปใช้เพิ่ม

- ทำสำเนา GameObject กับดักตัวอย่าง แล้วเปลี่ยนตำแหน่ง
- หนาม: วางตรงกลาง Tile และปรับ Interval Turns (เริ่มต้น 2)
  หากเว้น Target Tile ไว้ จะหาช่องจากตำแหน่งของกับดักเอง
- ธนู: วาง Fire Point ที่ความสูงลำตัว Player แล้วหันแกนสีน้ำเงิน (+Z) ไปทิศยิง
  ปรับ Interval Turns (เริ่มต้น 3), Arrow Speed, Range Tiles และ Hit Radius ได้
- โมเดลหนามและลูกธนูถูกสร้างเมื่อกด Play จึงไม่ต้องหา Arrow Prefab เพิ่ม
- ต้องมี TurnGameManager ในฉากเพื่อเรียก ResolveTurn

กับดักใหม่เป็นสคริปต์ TurnSpikeTrap / TurnArrowTrap แยกจาก Trap และ ArrowTrap เดิม

## วิธีลองใน Play Mode

1. เดิน Player มาที่แผ่นหนาม แล้ว Skip ให้จบคิว; ก่อนท้ายเทิร์น 2 จะยังไม่โดนหนาม
2. จบเทิร์น 2 ขณะยืนบนแผ่น: หนามพุ่งขึ้นและ Player ตาย; รอผ่านหลายเทิร์นแล้วหนามยังค้างอยู่
3. Restart แล้วปล่อย Player3 ยืนในแถวยิงเดิม; ใช้ End Turn ไปถึงท้ายเทิร์น 3 เพื่อทดสอบธนู
4. ย้าย Player ออกจากแถวยิงก่อนเทิร์น 3: ลูกธนูผ่านช่องว่างและหยุดเมื่อชนกำแพง
5. ปิด GameObject กับดัก: กับดักนั้นจะไม่ทำงาน; Restart จะรีเซ็ตเลขเทิร์นและรอบทั้งหมด
6. หลังท้ายเทิร์น 2 ให้ Player เดินเข้าช่องหนามที่ยังขึ้นอยู่: ตายทันทีที่เข้าช่องและหยุดเส้นทางเดิน
7. เมื่อเชื่อม Event ในอนาคต: ส่ง RequestLower ไปกับดักหนึ่งตัวแล้วตรวจว่าลงเฉพาะตัวนั้น
