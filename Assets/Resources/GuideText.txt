// Goal page
[goal01]
<b>เป้าหมายของการผจญภัย</b>
นำ <b>หีบสมบัติ</b> กลับไปยังกิลด์ เพียงนักผจญภัย <b>1 คน</b> เดินเข้าสู่ช่องเดียวกับหีบสมบัติ ก็ผ่านดันเจี้ยนได้

<b>วิธีเดิน</b>
1. เลือกนักผจญภัยที่ต้องการ
2. เลือก <b>เดิน</b>
3. กดช่องที่เรืองแสงเพื่อเดินไปยังช่องนั้น

[goal02]
<b>ซ้ายบน · นักผจญภัย</b>
แสดงไอคอนนักผจญภัยที่ควบคุมได้ กดไอคอนเพื่อเลือกตัวละครและดูตำแหน่งในดันเจี้ยน

<b>ขวาบน · ภัยอันตราย</b>
กดไอคอนเพื่อดูตำแหน่งของภัยอันตรายในดันเจี้ยน

<u>ก่อนเริ่มสำรวจ</u> สามารถดูรายชื่อตัวละครและภัยอันตรายได้ที่รายละเอียดเควส

[goal03]
<b>อ่านนาฬิกาพก</b>
นาฬิกาทางขวาล่างแสดงจำนวนเทิร์นที่มี และระบุเทิร์นที่กลไกบางอย่างจะทำงาน

<b>จบเทิร์นก่อนใช้การกระทำครบ</b>
<u>กดค้างที่นาฬิกา</u> เพื่อจบเทิร์นได้ทันที

// Skills page
[skills01]
<b>ความสามารถ · ฟันดาบ</b>
นักรบใช้ดาบโจมตีและสังหารตัวละครเป้าหมายได้

<b>เป้าหมายที่โจมตีได้</b>
ทั้งนักผจญภัยและเจ้ากระดูก

[skills02]
<b>ความสามารถ · ยิงธนู</b>
นักธนูยิงลูกธนูไปในทิศทางหนึ่งได้ <b>1 ครั้ง</b>

<u>ระวัง</u> ลูกธนูสามารถทำลายหรือสังหารตัวละครได้ <b>ทุกฝ่าย</b>

[skills03]
<b>ความสามารถ · สะเดาะกลอน</b>
โจรปลดล็อกกลอนประตูได้ <b>1 ครั้ง</b>

<u>เงื่อนไข</u> ใช้ได้เฉพาะประตูที่มีกลอนเท่านั้น

// Mechanism page
[mecha01]
<b>เปิดทางสู่หีบสมบัติ</b>
ประตูกลขวางทางระหว่างนักผจญภัยกับหีบสมบัติ โดยอาศัยกลไก เช่น คันโยก เป้ายิง หรือแท่นเหยียบ เพื่อเปิดหรือปิด

<b>การรับสัญญาณ</b>
เมื่อได้รับหรือสูญเสียสัญญาณ ประตูจะเปิดหรือปิดตามกลไก

<u>ข้อควรรู้</u> ไม่ว่าจะรับสัญญาณจากกี่จุด ก็มีผลเท่ากับ <b>1 สัญญาณ</b>

[mecha02]
ตัวส่งสัญญาณใช้ควบคุมประตูและกลไกที่รับสัญญาณ

<b>คันโยก</b> · โยกเพื่อเปิด/ปิดสัญญาณ สถานะจะคงอยู่จนกว่าจะโยกอีกครั้ง

<b>แท่นเหยียบ</b> · ส่งสัญญาณขณะมีตัวละครหรือวัตถุวางอยู่ <u>ใช้ศพแทนไม่ได้</u>

<b>เป้ายิง</b> · เมื่อลูกธนูยิงโดนเป้า จะส่งสัญญาณ <b>ถาวร</b>

[mecha03]
<b>ลูกธนูและการปะทะ</b>
ลูกธนูสามารถทำลายหรือสังหารตัวละครได้ <b>ทุกฝ่าย</b>

<b>สิ่งที่หยุดลูกธนู</b>
ลูกธนูจะถูกทำลายเมื่อชนกำแพง

[mecha04]
<b>พื้นที่เปลี่ยนตามเวลา</b>
พื้นที่ในดันเจี้ยนอาจเปลี่ยนแปลงไป เช่น
- บางช่องถูกปิดหรือหายไป
- มีพื้นที่เพิ่มขึ้นอีกหนึ่งช่อง

<u>สังเกตสภาพแวดล้อม</u> พื้นที่รูปแบบอื่นอาจส่งผลต่อทั้งดันเจี้ยนได้เช่นกัน

// Hazards page
[hazards01]
เจ้ากระดูกมีทั้ง <b>ดาบ</b> และ <b>ธนู</b> หากยัง <b>เกรี้ยวกราด</b> ตอนจบเทิร์น จะโจมตีผู้เล่น

<b>ดาบ</b> · เกรี้ยวกราดเมื่อมีนักผจญภัยอยู่ด้านหน้า 1 ช่อง และโจมตีเฉพาะช่องนั้น

<b>ธนู</b> · เกรี้ยวกราดเมื่อเห็นนักผจญภัยหรือศพในทิศที่หันอยู่ และยิงธนูไปด้านหน้า

<u>ทั้งสองแบบโจมตีไม่ทะลุกำแพงหรือสิ่งกีดขวาง</u>

[hazards02]
<b>กับดักหน้าไม้ทำงานเมื่อใด</b>
ยิงลูกธนูไปด้านหน้าของตัวเอง <b>ตอนจบเทิร์น</b> ตามเงื่อนไขที่กำหนด

<b>ตัวอย่างเงื่อนไข</b>
- ยิงทุก ๆ 2 เทิร์น
- ยิงเมื่อได้รับสัญญาณ
