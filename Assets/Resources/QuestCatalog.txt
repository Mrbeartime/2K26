# ผูกข้อมูลกับ ID ใน SceneCatalog ใช้ [level:เลข ID] หรือ [secret:ID ด่านลับ]
# characters เรียงชื่อจากซ้ายไปขวา คั่นด้วยจุลภาค ชื่อที่ตั้งไว้คือ Rogue, Warrior, Archer
# paper ใช้ default หรือชื่อ Sprite ใน QuestPaper ได้แก่ paper_0, paper_1, paper_2
# depth รับค่า 0–10 และ description ใช้ \n เพื่อขึ้นบรรทัดใหม่ได้
# เงื่อนไขปลดล็อกทุกข้อที่ใส่ต้องผ่านพร้อมกัน เว้นว่างหรือลบบรรทัดเพื่อปิดเงื่อนไขนั้น
# unlockMain ใช้ ID ด่านหลัก และ unlockSecret ใช้ ID ด่านลับ คั่นด้วยจุลภาค
# unlockCount คือจำนวนด่านที่ต้องผ่าน
# unlockMinDepth ต้องเคยผ่านอย่างน้อยหนึ่งด่านที่มี Depth ถึงค่านี้
# unlockTotalDepth คือผลรวม Depth ของด่านที่ผ่าน
