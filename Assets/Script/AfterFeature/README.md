# Level stars (1–3)

- เลือก `LevelStarSettings.asset` ในโฟลเดอร์นี้ แล้วเพิ่ม Scene ใน Scene Rules ด้วยการลาก Scene asset
- แต่ละ Scene กำหนดเกณฑ์ 2 ดาวและ 3 ดาวได้ แถวนั้นต้องผ่านทั้งจำนวนเทิร์นที่เหลือและจำนวนตัวละครที่รอด
- Minimum Stars On Victory ตั้งดาวขั้นต่ำตอนผ่านได้ (เริ่มต้น 1 ดาว) แพ้เกมไม่บันทึกดาว
- Character Source เลือกนับ Players In This Scene หรือ Assigned Characters ที่ลากใส่เองได้ เปิด Include Inactive Characters หากต้องการนับตัวที่ปิดใช้งานด้วย ตัวที่ตายไม่นับเสมอ
- Save Best To Json และ Log Results เปิด/ปิดได้จาก Inspector ของ LevelStarRating
- ค่าเริ่มต้นทุกด่าน: 2 ดาวต้องเหลือเทิร์น >= 1; 3 ดาวต้องเหลือเทิร์น >= 3
- จำนวนผู้รอดสำหรับ 2/3 ดาว: Level1 = 1/1 คน, Level2 = 1/2 คน, Level3–5 = 2/3 คน อิงจำนวนผู้เล่นเริ่มต้นที่เปิดใช้งาน และปรับเองใน Inspector ได้
- ตัวอย่าง Level3–5: เหลือ 4 เทิร์น/3 คน = 3 ดาว; 2 เทิร์น/3 คน = 2 ดาว; 4 เทิร์น/1 คน = 1 ดาว
- เพิ่ม `LevelStarRating` บน GameObject เดียวกับ `TurnGameManager` และใส่ Settings asset ให้ component นี้
- ด่านหลัก Level1–Level5 ผูกให้แล้ว ด่านใหม่ต้องเพิ่มทั้ง Rule และ component; Scene ที่ไม่มี Rule จะไม่บันทึกดาว
- จำนวนผู้รอดนับเฉพาะ Character ของ PlayerMove ที่ยังไม่ตาย เปิดใช้งาน และอยู่ใน Scene เดียวกัน ไม่นับศัตรู/ศพ/ตัวละครจาก Additive Scene อื่น
- นับ TurnsLeft ณ จังหวะ GameEnded(true) รวมเทิร์นปัจจุบันตามระบบ TurnGameManager ไม่หักเทิร์นเพิ่ม
- เก็บเฉพาะคะแนนดีที่สุด เล่นซ้ำได้น้อยกว่าเดิมจะไม่ลบดาวเก่า
- JSON เดิมที่ไม่มีฟิลด์ดาวยังโหลดได้และเริ่มที่ 0 ดาว จนกว่าจะชนะด้วยระบบนี้
- ด่านหลักเก็บใน `levels[].stars`; Scene อื่นเก็บใน `sceneStars[]` โดยใช้ scenePath
- Editor บันทึกที่ `Assets/Script/SceneManager/level-progress.json`; ตัวเกม Build บันทึกที่ Application.persistentDataPath
- หน้าเลือกด่านใช้ LevelStarsGraphic เป็นลูกของแต่ละปุ่มใน Hierarchy ไม่รับ Raycast และไม่ได้ปรับขนาด UI เดิม
- ด่านที่ completed จะซ่อนจากหน้าหลักตามระบบเดิม ให้ดูดาวและเลือกเล่นซ้ำใน Complete
- คะแนนรอบล่าสุดดูใน LevelStarRating และเชื่อม On Stars Awarded (int) กับ UI/Animation ของคุณได้ โดยไม่สร้าง UI ตอน runtime
